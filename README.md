# 📚 Study AI Assistant

An AI-powered Study Assistant built using **Streamlit** and **Google Gemini AI**. This application helps students understand concepts, answer academic questions, summarize topics, and provide intelligent learning support through natural language conversations.

---

## 🚀 Features

- 🤖 AI-powered study assistant
- 📖 Answers academic questions instantly
- 📝 Explains concepts in simple language
- 📚 Knowledge Injection support
- 💬 Interactive chat interface
- ⚡ Fast and lightweight Streamlit application
- 🎯 Personalized learning experience

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- Google Generative AI SDK

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/study-ai-assistant.git
```

Navigate to the project

```bash
cd study-ai-assistant
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```

---

## 🔑 API Configuration

Create a Gemini API Key from Google AI Studio and configure it in your application.

Example:

```python
genai.configure(api_key="YOUR_API_KEY")
```

## 📚 Knowledge Injection

The assistant supports custom knowledge injection, allowing users to upload domain-specific information such as:

- Notes
- Study Material
- Research Documents
- Course PDFs
- Custom Knowledge Bases

This enables the AI to answer questions based on the provided learning resources.
